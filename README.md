### Contribution snake setup

1. Keep this repository public and named exactly `Yogesh7564` (it is the special profile repository).
2. Add `.github/workflows/snake.yml` from this repository. Ensure **Actions → General → Workflow permissions** allows read and write access to repository contents, or otherwise grant the workflow the required `contents: write` permission.
3. Enable Actions, then run **Actions → Generate contribution snake → Run workflow** once. The scheduled job runs daily at 00:17 UTC; scheduled workflows can be delayed by GitHub and may be disabled after prolonged repository inactivity.
4. On success, the action publishes SVG assets to the `output` branch. The images above use that branch. No personal access token or user secret is required; the workflow uses the repository-scoped `GITHUB_TOKEN`.
5. The snake action reads the public contribution calendar for this username. It does not expose private contribution details or invent activity.

### Live data and service limits

- GitHub Readme Stats, Streak Stats, Activity Graph, shields.io, and the contribution calendar image are third-party hosted services; availability, caching, rate limits, and appearance are outside this repository's control.
- GitHub profile README does not execute JavaScript, custom CSS, arbitrary scripts, or interactive 3D effects. HTML tables and linked image cards are static responsive-friendly alternatives; hover effects are not guaranteed.
- GitHub does not provide a built-in live “currently coding” indicator or a reliable public API for total coding hours. No such claim is made here.
- Public profile repository statistics do not equal all private work. Contribution totals follow GitHub's contribution rules, and third-party cards may cache data.
- LeetCode does not provide a stable official public profile statistics API for this README; stats are omitted rather than guessed.
- The profile-view badge reports aggregate image requests from its service. It is not a unique-visitor or recruiter-analytics measure.

### Troubleshooting

- **Snake image is missing:** check the latest workflow run and permissions, then confirm the `output` branch contains `github-contribution-grid-snake.svg` and `github-contribution-grid-snake-dark.svg`. Re-run manually if needed; allow time for raw GitHub/CDN caching.
- **Workflow cannot push:** check repository Actions workflow permissions and ensure the workflow has `contents: write`; organization policy may restrict `GITHUB_TOKEN` writes.
- **Cards are blank or stale:** third-party services can rate-limit or cache requests. Retry later; avoid adding secrets to image URLs or README content.
- **Contribution chart looks sparse:** verify GitHub's contribution settings and contribution attribution. GitHub controls which activity is counted.
